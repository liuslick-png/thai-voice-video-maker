# Thai Voice Video Maker

Offline Android prototype for turning a portrait and Thai text into a vertical narrated MP4.

## First test build

- Select a portrait from the phone
- Type Thai narration
- Use Android offline Text-to-Speech
- Render 720 × 1280 H.264 video with subtle camera motion
- Encode narration as AAC and mux to MP4
- Save to Movies/ThaiVoiceVideoMaker
- No cloud API and no third-party AI model

This first build validates the full offline image + voice + MP4 pipeline. Mouth shapes, blinking, breathing, and subtle head movement are the next stage after device compatibility is confirmed.
